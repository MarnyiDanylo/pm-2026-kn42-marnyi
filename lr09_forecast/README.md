## 2. Як рахувалася симуляція

| Поле | Значення |
| --- | --- |
| Інструмент | Власний скрипт Python |
| Прогонів | 10000 |
| Що тягнеться випадково | Фактична velocity одного з моїх спринтів (`random.choice([10, 8])`) |
| Дата, від якої відлічуються спринти прогнозу | Для сценарію «Весь перший реліз» — дата кінця Спринта 1 (2026-10-02 + $(P - 1) \times 14$ днів); для сценарію залишку — дата кінця Спринта 2 (2026-10-16 + $P \times 14$ днів) |

Код симуляції Monte Carlo:

```python
import random
from datetime import date, timedelta

# Історія фактичної velocity команди (Спринт 1: 10 SP, Спринт 2: 8 SP)
velocity_history = [10, 8]

def run_monte_carlo(remaining_points, n_simulations=10000):
    simulated_sprints = []
    for _ in range(n_simulations):
        rem = remaining_points
        sprints_count = 0
        while rem > 0:
            sprints_count += 1
            rem -= random.choice(velocity_history)
        simulated_sprints.append(sprints_count)

    simulated_sprints.sort()
    p50 = simulated_sprints[int(0.50 * n_simulations)]
    p85 = simulated_sprints[int(0.85 * n_simulations)]
    return p50, p85

# Розрахунок сценаріїв:
# 1. Весь перший реліз (36 points)
p50_all, p85_all = run_monte_carlo(36)
d_end1 = date(2026, 10, 2)
p50_date_all = d_end1 + timedelta(days=14 * (p50_all - 1))
p85_date_all = d_end1 + timedelta(days=14 * (p85_all - 1))

# 2. Залишок після двох спринтів (18 points)
p50_left, p85_left = run_monte_carlo(18)
d_end2 = date(2026, 10, 16)
p50_date_left = d_end2 + timedelta(days=14 * p50_left)
p85_date_left = d_end2 + timedelta(days=14 * p85_left)
```
