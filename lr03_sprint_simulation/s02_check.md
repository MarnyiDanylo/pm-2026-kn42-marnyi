# S-02. Вибір своєї групи: протокол перевірки критеріїв приймання

Дата: 2026-10-16 (Огляд Спринта 1).
Історія: `S-02`, 3 SP, Epic: Доступ.

## Потік перевірки

1. Після першої успішної авторизації користувач потрапляє на екран майстра налаштування профілю.
2. Відображається випадаючий список доступних факультетів академії.
3. Після вибору факультету активується список відповідних навчальних груп.
4. Після натискання кнопки "Зберегти" обрана група записується у локальне сховище застосунку (`SharedPreferences` / `UserDefaults`).
5. При наступних запусках цей екран пропускається автоматично.
