# S-07. Налаштування сповіщень: протокол перевірки критеріїв приймання

Дата: 2026-10-16 (Огляд Спринта 1).
Історія: `S-07`, 2 SP, Epic: Сповіщення.

## Потік перевірки

1. Користувач переходить у розділ "Налаштування" -> "Сповіщення".
2. Відображається перемикач "Нічний режим / Не турбувати (22:00 - 07:00)".
3. При активації тумблера фонові push-повідомлення у вказаний діапазон переводяться у беззвучний режим без вібрації та спливаючого банера.
4. За замовчуванням користувач підписаний тільки на топік своєї навчальної групи; сповіщення про інші групи автоматично відфільтровані.
